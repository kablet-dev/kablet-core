# VELORA demo assets

This directory is a development-only placement for the fictional VELORA merchant fixture. It is not a production merchant asset bucket.

Install the exact files listed in [`docs/demo/VELORA_ASSET_MANIFEST.md`](../../../../docs/demo/VELORA_ASSET_MANIFEST.md) before running `pnpm seed:velora-demo`.

Do not hotlink images, add the composite UI reference, or use assets without recorded usage authorization.
